# MarkFree

免费的本地图片水印工具，基于 Vue 3、TypeScript、Vite 和 Ant Design Vue。

- 支持 JPG、PNG、WebP 图片，多选或拖拽批量导入，单张最大 50MB。
- 支持文字与 Logo 水印：支持真实多行文本换行、多种字体风格选择、颜色、透明度、旋转角度以及立体柔和阴影。
- 智能布局与密度：支持预设及拖拽微调位置，平铺水印支持平铺间距密度调节与交错错位排版（Stagger Grid）。
- 原图分辨率自适应：支持根据图片实际分辨率等比缩放字号，保证在不同尺寸图片上视觉大小均衡。
- 细节放大预览：支持画布「自适应居中 / 1:1 实际原始像素」一键切换，方便高清照片细节检视。
- 默认使用统一水印（自动持久化保存到本地 LocalStorage）；选中图片后开启「单独设置当前图片」即可独立调整，也可一键恢复。
- 支持单张图片导出或批量打包下载 ZIP，支持自定义导出格式（PNG 无损 / JPG 紧凑 / WebP 高效）与画质压缩。
- 图片仅在浏览器内本地安全处理，绝不上传服务器。
- 支持 PWA 渐进式应用：可直接“安装到电脑/手机桌面”，在断网与无网络环境下 100% 离线使用。

## 本地开发

```sh
npm install
npm test
npm run dev
```

## 构建和预览

```sh
npm run build
npm run preview
```
